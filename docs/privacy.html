Privacy Policy

Last updated: May 2026

Last updated: 2026-05-12 14:57 UTC

Summary

HantavirusMap.site is a static, open-data tracker. We do not collect personal information, do not use tracking cookies, and do not require accounts or sign-ups.

What we do not collect

  • No names, emails, or contact details
  • No IP addresses or location data
  • No browser fingerprints or device information
  • No cookies for tracking or advertising
  • We use GoatCounter, a privacy-first, open-source analytics tool that does not use cookies or track personal information.

What we do use

  • GoatCounter (optional, privacy-first) — If enabled, we may use GoatCounter, an open-source analytics tool that does not track personal data, does not use cookies, and is GDPR-friendly. You can read more at goatcounter.com.
  • GitHub Pages hosting — This site is hosted on GitHub Pages. GitHub may log standard server access data (IP, user agent, timestamp) as part of their infrastructure operations. See GitHub's Privacy Statement.

Third-party content

This site links to external sources (CDC, WHO, ProMED-mail, Google News) and embeds a map using Leaflet with Esri World Imagery tiles. These third parties have their own privacy policies and data practices.

Data sources

All outbreak data is pulled from publicly available sources (ProMED-mail RSS, Google News RSS, CDC publications). No private or proprietary health data is used.

Changes to this policy

If we add features that change how data is handled, we will update this page and note the change date above.

Contact

Questions about this privacy policy? Open an issue on GitHub or contact jimmy.xb@gmail.com.
